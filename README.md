# 아버지 병원 치료 · 공개 프로젝트 안내

이 저장소는 공개 가능한 프로젝트 안내와 비공개 자료의 접근 링크만 제공합니다. 상세 의료·보험 기록과 사진·문서·음성·영상 원본은 공개하지 않습니다.

**[🔒 Vercel 인증 후 비공개 프로젝트 열기](https://father-hospital-treatment-private.vercel.app/)**

[전체 프로젝트 인덱스](https://softm.github.io/projects/)

## 현재 상태

비공개 기록 7개가 등록되어 있습니다. 공개 안내 홈 소스 `index.html`을 생성했습니다. 다만 공개 웹의 배포 완료와 이번 변경 후 비공개 Vercel 재배포는 확인되지 않았습니다. 최신 비공개 저장소와 운영 사이트 연결을 점검해야 합니다.

본문·첨부 원본은 GitHub Private에 보관하고, Vercel 서버가 인증 후 요청 시 읽는 방식이 전역 기준입니다. 직접 파일 주소도 인증되어야 하며, 원본 포함 및 재생 검증은 별도 항목입니다.

[전역 아카이브 배포 규칙](https://github.com/softm/softm.github.io/blob/main/projects/README.md)
